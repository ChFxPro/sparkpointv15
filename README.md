
  # SparkPoint V15

  This is a code bundle for SparkPoint V15. The original project is available at https://www.figma.com/design/eiECrQAtFNx2YuehI5swOs/SparkPoint-V15.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  Run `PUBLIC_BASE='/sparkpointv15/' SITE_ORIGIN='https://chfxpro.github.io/sparkpointv15' npm run build` for GitHub Pages builds.

  Run `PUBLIC_BASE='/' SITE_ORIGIN='https://www.yoursparkpoint.org' npm run build` for root-domain builds.
